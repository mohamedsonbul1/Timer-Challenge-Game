# Timer challenge

Stop the timer as close to the target time as you can. A small game to practise `useRef` for values that should not trigger re-renders, `forwardRef`/`useImperativeHandle` for the result dialog, and portals for rendering the modal outside the component tree.

React 18 + Vite.

```bash
npm install && npm run dev
```

# Timer-Challenge

Den Timer so nah wie möglich an der Zielzeit stoppen. Ein kleines Spiel zum Üben von `useRef` für Werte, die kein Re-Rendering auslösen sollen, `forwardRef`/`useImperativeHandle` für den Ergebnisdialog und Portals, um das Modal außerhalb des Komponentenbaums zu rendern.

React 18 + Vite.
